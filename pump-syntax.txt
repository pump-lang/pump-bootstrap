Pump Language Specification v0.1 - bản nháp.

Ghi lại để khỏi quên. Ưu tiên: cú pháp dễ đọc, explicit, grammar nhỏ, compiler parse
nhanh. Không bê nguyên Rust/Go/Python vào.

## Pump

Triết lý cú pháp:

> **simple syntax, explicit behavior, fast compilation**

Pump có runtime GC, nhưng GC hoàn toàn nằm ngoài syntax.

### 1. Chương trình

Một file Pump:

```pump
import io

const VERSION: string = "0.1"

fn main() {
    let name: string = "Minh"
    io.println("Hello " + name)

    return
}
```

Không bắt buộc `;`.

Statement được kết thúc bởi newline hoặc `}`.

Nếu cần nhiều statement trên một dòng:

```pump
let a = 10; let b = 20
```

Nhưng style chuẩn vẫn là mỗi statement một dòng.

## 2. Binding

Chỉ có **hai keyword**:

```pump
let
const
```

`let` khả biến:

```pump
let count = 0
count = 10
count += 1
```

`const` bất biến:

```pump
const name = "Pump"
```

Không thể:

```pump
const x = 10
x = 20
```

Compiler báo lỗi.

Type annotation:

```pump
let age: int = 18
const name: string = "Minh"
```

Inference:

```pump
let age = 18
const name = "Minh"
```

## 5. Function

Function dùng `fn`.

```pump
fn add(a: int, b: int): int {
    return a + b
}
```

Không return:

```pump
fn hello(name: string) {
    print("Hello " + name)
}
```

Return luôn explicit:

```pump
fn max(a: int, b: int): int {
    if a > b {
        return a
    }

    return b
}
```

Không có chuyện:

```pump
a + b
```

tự động trở thành return như Rust.

## 7. If


## 9. For

Pump dùng `for ... in`.

```pump
for item in items {
    print(item)
}
```

Range:

```pump
for i in 0..10 {
    print(i)
}
```

`0..10` là từ 0 đến 9.

Inclusive:

```pump
for i in 0..=10 {
    print(i)
}
```

---

## 10. Break / continue

```pump
for item in items {
    if item == 0 {
        continue
    }

    if item < 0 {
        break
    }

    print(item)
}
```

```pump
    name: string
```

```pump
let user = User {
    name: "Minh"
```

Field:

```pump
print(user.name)
```

## 12. Methods

Method nằm trực tiếp trong struct:

```pump
struct User {
    name: string
    age: int

    fn greet() {
        print("Hello " + name)
    }
}
```

Gọi:

```pump
user.greet()
```

Không cần `self`.

Trong method, field của object hiện tại được resolve trực tiếp.

Nếu cần explicit receiver:

```pump
fn rename(name: string) {
    this.name = name
}
```

Pump dùng `this`, không dùng `self`.

## 14. Match

```pump
match color {
    Color.Red => {
        print("red")
    }

    Color.Green => {
        print("green")
    }

    Color.Blue => {
        print("blue")
    }
}
```

Wildcard:

```pump
match value {
    0 => print("zero")
    1 => print("one")
    _ => print("other")
}
```

## 15. Optional

Optional dùng `?`.

```pump
fn find(id: int): User? {
    ...
}
```

Giá trị có thể tồn tại hoặc không.

```pump
let user: User? = find(10)
```

Check:

```pump
if user != null {
    print(user.name)
}
```

Unwrap:

```pump
let actual = user?
```

Phần `?` này cần grammar phân biệt rõ giữa optional type và postfix unwrap.

---

## 16. Error handling

Pump không dùng exception làm cơ chế duy nhất.

Function có thể khai báo error:

```pump
fn read_file(path: string): string! {
    ...
}
```

Propagate:

```pump
fn load(): string! {
    let data = read_file("data.txt")!
    return data
}
```

Handle:

```pump
let data = read_file("data.txt") catch {
    return ""
}
```

Mục tiêu là error handling explicit nhưng không biến thành Rust `Result<T, E>` everywhere.

## 18. Interfaces

Pump cần abstraction nhưng không nên gọi là `trait`.

```pump
interface Printable {
    fn print()
}
```

Implement:

```pump
struct User {
    name: string

    fn print() {
        io.println(name)
    }
}
```

Compiler có thể tự kiểm tra structural conformance.

Nếu muốn explicit:

```pump
implements User: Printable
```

## 21. Constants

Compile-time constant:

```pump
const MAX_USERS: int = 1000
const VERSION: string = "1.0"
```

Runtime immutable data vẫn dùng `const`:

```pump
const config = load_config()
```

Ở đây `const` nghĩa là binding không thể reassigned; compiler/runtime sẽ phân biệt compile-time constant với runtime immutable value.

## 22. Closures

Cú pháp:

```pump
let add = fn(a: int, b: int): int {
    return a + b
}
```

Nếu cần shorthand:

```pump
let add = (a, b) => a + b
```

Nhưng nghiêng về **không đưa `=> expression` vào core syntax v0.1**. Function bình thường đã đủ rõ và grammar nhỏ hơn.

## 23. Lambda callback

Sau này có thể thêm shorthand mà không phá semantics.

## 26. Concurrency

Không cần keyword kiểu `async`, `await` ngay từ đầu.

Runtime GC + scheduler có thể cung cấp:

```pump
spawn fn() {
    server.start()
}
```

Channel:

```pump
let channel = channel<int>()

channel.send(10)

let value = channel.receive()
```

Nhưng đây là **stdlib/runtime API**, không phải core language.

## 28. Syntax không nên có

T sẽ cố tình loại:

```text
;
```

không bắt buộc.

Không:

```text
-> int
```

mà:

```text
: int
```

Không:

```text
var
```

chỉ:

```text
let
const
```

Không implicit return kiểu Rust.

Không `self`.

Dùng:

```text
this
```

Không `elif`.

Không macro syntax trong core.

Không lifetime syntax.

Không ownership syntax.

Không `pub(crate)` kiểu Rust.

Không hàng chục modifier.

## 29. Một chương trình Pump thực tế

```pump
import io
import net\http

const PORT: int = 8080

struct User {
    name: string
    age: int

    fn greet() {
        io.println("Hello " + name)
    }
}

fn create_user(name: string, age: int): User {
    let user = User {
        name: name
        age: age
    }

    return user
}

fn main() {
    let user = create_user("Minh", 18)

    if user.age >= 18 {
        user.greet()
    } else {
        io.println("Minor")
    }

    for i in 0..10 {
        io.println(i)
    }

    return
}
```

Hướng này hợp Pump hơn: **cú pháp nhìn quen ngay lập tức, nhưng không clone một ngôn ngữ cụ thể nào**.

Nhắc mình: đây MỚI LÀ DRAFT, chưa đóng. Bước tiếp theo phải là viết grammar EBNF
hoàn chỉnh cho toàn bộ syntax trên, rồi cố tình đi tìm ambiguity và edge case của
parser. Khi grammar đó sạch thì mới đóng được Pump Syntax 1.0.
