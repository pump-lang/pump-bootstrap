Pump Language Specification v0.1 - bản nháp.

Ghi lại để khỏi quên. Ưu tiên: cú pháp dễ đọc, explicit, grammar nhỏ, compiler parse
nhanh. Không bê nguyên Rust/Go/Python vào.

## Pump

Triết lý cú pháp:

> **simple syntax, explicit behavior, fast compilation**

Pump có runtime GC, nhưng GC hoàn toàn nằm ngoài syntax.

### 1. Chương trình

Một file Pump:

```pump
import io

const VERSION: string = "0.1"

fn main() {
    let name: string = "Minh"
    io.println("Hello " + name)

    return
}
```

Không bắt buộc `;`.

Statement được kết thúc bởi newline hoặc `}`.

Nếu cần nhiều statement trên một dòng:

```pump
let a = 10; let b = 20
```

Nhưng style chuẩn vẫn là mỗi statement một dòng.

---

## 2. Binding

Chỉ có **hai keyword**:

```pump
let
const
```

`let` khả biến:

```pump
let count = 0
count = 10
count += 1
```

`const` bất biến:

```pump
const name = "Pump"
```

Không thể:

```pump
const x = 10
x = 20
```

Compiler báo lỗi.

Type annotation:

```pump
let age: int = 18
const name: string = "Minh"
```

Inference:

```pump
let age = 18
const name = "Minh"
```

```text
bool
int
uint
float
char
string
```

Literal:

```pump
true
false

42
```

```pump

```

## 4. Collection

Array:

```pump
let numbers: [int] = [1, 2, 3, 4]
```

Map:

```pump

```

Set:

```pump
let ids: set<int> = {}
```

Tuple:

```pump
let point: (int, int) = (10, 20)
```

Index:

```pump
let first = numbers[0]
```

## 5. Function

Function dùng `fn`.

```pump
fn add(a: int, b: int): int {
    return a + b
}
```

Không return:

```pump
fn hello(name: string) {
    print("Hello " + name)
}
```

Return luôn explicit:

```pump
fn max(a: int, b: int): int {
    if a > b {
        return a
    }

    return b
}
```

Không có chuyện:

```pump
a + b
```

tự động trở thành return như Rust.

## 6. Parameters

Normal:

```pump
fn greet(name: string) {
    print(name)
}
```

Default:

```pump
fn connect(host: string, port: int = 80) {
    ...
}
```

Named arguments:

```pump
connect( host: "localhost", port: 8080 )
```

Variadic:

```pump
fn sum(values: ...int): int {
    ...
}
```

---

## 7. If

```pump
if age >= 18 {
    print("adult")
} else {
    print("minor")
}
```

Else-if:

```pump
if score >= 9 {
    print("A")
} else if score >= 80 {
    print("B")
} else {
    print("C")
}
```

Không dùng `elif`.

---

## 8. While

```pump
let i = 0

while i < 10 {
    print(i)
    i += 1
}
```

---

## 9. For

Pump dùng `for ... in`.

```pump
for item in items {
    print(item)
}
```

Range:

```pump
for i in 0..10 {
    print(i)
}
```

`0..10` là từ 0 đến 9.

Inclusive:

```pump
for i in 0..=10 {
    print(i)
}
```

---

## 10. Break / continue

```pump
for item in items {
    if item == 0 {
        continue
    }

    if item < 0 {
        break
    }

    print(item)
}
```
