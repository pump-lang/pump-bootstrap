Pump Language Specification v0.1 - bản nháp.

Ghi lại để khỏi quên. Ưu tiên: cú pháp dễ đọc, explicit, grammar nhỏ, compiler parse
nhanh. Không bê nguyên Rust/Go/Python vào.

## Pump

Triết lý cú pháp:

> **simple syntax, explicit behavior, fast compilation**

Pump có runtime GC, nhưng GC hoàn toàn nằm ngoài syntax.

### 1. Chương trình

Một file Pump:

```pump
import io

const VERSION: string = "0.1"

fn main() {
    let name: string = "Minh"
    io.println("Hello " + name)

    return
}
```

Không bắt buộc `;`.

Statement được kết thúc bởi newline hoặc `}`.

Nếu cần nhiều statement trên một dòng:

```pump
let a = 10; let b = 20
```

Nhưng style chuẩn vẫn là mỗi statement một dòng.

---

## 2. Binding

Chỉ có **hai keyword**:

```pump
let
const
```

`let` khả biến:

```pump
let count = 0
count = 10
count += 1
```

`const` bất biến:

```pump
const name = "Pump"
```

Không thể:

```pump
const x = 10
x = 20
```

Compiler báo lỗi.

Type annotation:

```pump
let age: int = 18
const name: string = "Minh"
```

Inference:

```pump
let age = 18
const name = "Minh"
```

## 5. Function

Function dùng `fn`.

```pump
fn add(a: int, b: int): int {
    return a + b
}
```

Không return:

```pump
fn hello(name: string) {
    print("Hello " + name)
}
```

Return luôn explicit:

```pump
fn max(a: int, b: int): int {
    if a > b {
        return a
    }

    return b
}
```

Không có chuyện:

```pump
a + b
```

tự động trở thành return như Rust.

## 6. Parameters

Normal:

```pump
fn greet(name: string) {
    print(name)
}
```

Default:

```pump
fn connect(host: string, port: int = 80) {
    ...
}
```

Named arguments:

```pump
connect(
    host: "localhost",
    port: 8080
)
```

Variadic:

```pump
fn sum(values: ...int): int {
    ...
}
```

## 7. If

```pump
if age >= 18 {
    print("adult")
} else {
    print("minor")
}
```

Else-if:

```pump
if score >= 90 {
    print("A")
} else if score >= 80 {
    print("B")
} else {
    print("C")
}
```

Không dùng `elif`.

## 8. While

```pump
let i = 0

while i < 10 {
    print(i)
    i += 1
}
```

---

## 9. For

Pump dùng `for ... in`.

```pump
for item in items {
    print(item)
}
```

Range:

```pump
for i in 0..10 {
    print(i)
}
```

`0..10` là từ 0 đến 9.

Inclusive:

```pump
for i in 0..=10 {
    print(i)
}
```

---

## 10. Break / continue

```pump
for item in items {
    if item == 0 {
        continue
    }

    if item < 0 {
        break
    }

    print(item)
}
```

## 11. Struct

```pump
struct User {
    name: string
    age: int
}
```

Khởi tạo:

```pump
let user = User {
    name: "Minh"
    age: 18
}
```

Field:

```pump
print(user.name)

user.age = 19
```

---

## 12. Methods

Method nằm trực tiếp trong struct:

```pump
struct User {
    name: string
    age: int

    fn greet() {
        print("Hello " + name)
    }
}
```

Gọi:

```pump
user.greet()
```

Không cần `self`.

Trong method, field của object hiện tại được resolve trực tiếp.

Nếu cần explicit receiver:

```pump
fn rename(name: string) {
    this.name = name
}
```

Pump dùng `this`, không dùng `self`.

## 13. Enum

Simple enum:

```pump
enum Color {
    Red
    Green
    Blue
}
```

Payload:

```pump
enum Result<T, E> {
    Ok(T)
    Err(E)
}
```

## 14. Match

```pump
match color {
    Color.Red => {
        print("red")
    }

    Color.Green => {
        print("green")
    }

    Color.Blue => {
        print("blue")
    }
}
```

Wildcard:

```pump
match value {
    0 => print("zero")
    1 => print("one")
    _ => print("other")
}
```

---

## 15. Optional

Optional dùng `?`.

```pump
fn find(id: int): User? {
    ...
}
```

Giá trị có thể tồn tại hoặc không.

```pump
let user: User? = find(10)
```

Check:

```pump
if user != null {
    print(user.name)
}
```

Unwrap:

```pump
let actual = user?
```

Phần `?` này cần grammar phân biệt rõ giữa optional type và postfix unwrap.

---

## 16. Error handling

Pump không dùng exception làm cơ chế duy nhất.

Function có thể khai báo error:

```pump
fn read_file(path: string): string! {
    ...
}
```

Propagate:

```pump
fn load(): string! {
    let data = read_file("data.txt")!
    return data
}
```

Handle:

```pump
let data = read_file("data.txt") catch {
    return ""
}
```

Mục tiêu là error handling explicit nhưng không biến thành Rust `Result<T, E>` everywhere.

## 17. Generics

```pump
fn first<T>(items: [T]): T? {
    if items.length == 0 {
        return null
    }

    return items[0]
}
```

Struct:

```pump
struct Box<T> {
    value: T
}
```

Enum:

```pump
enum Result<T, E> {
    Ok(T)
    Err(E)
}
```

## 18. Interfaces

Pump cần abstraction nhưng không nên gọi là `trait`.

```pump
interface Printable {
    fn print()
}
```

Implement:

```pump
struct User {
    name: string

    fn print() {
        io.println(name)
    }
}
```

Compiler có thể tự kiểm tra structural conformance.

Nếu muốn explicit:

```pump
implements User: Printable
```

## 20. Visibility

Chỉ cần hai mức:

```pump
pub
private
```

Ví dụ:

```pump
pub fn start() {
    ...
}

fn internal() {
    ...
}
```

Mặc định là private.

---

## 21. Constants

Compile-time constant:

```pump
const MAX_USERS: int = 1000
const VERSION: string = "1.0"
```

Runtime immutable data vẫn dùng `const`:

```pump
const config = load_config()
```

Ở đây `const` nghĩa là binding không thể reassigned; compiler/runtime sẽ phân biệt compile-time constant với runtime immutable value.
